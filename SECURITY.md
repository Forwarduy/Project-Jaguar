# Security Policy

## Supported Versions

| Version | Supported |
| ------- | ------------------ |
| 0.1.x | :white_check_mark: |

## Reporting a Vulnerability

Do NOT open public issues for security bugs.

Email: forwarduy@gmail.com or DM on GitHub.
We will respond within 48h.

If accepted, we will:
1. Fix and release patch
2. Credit you in SECURITY.md (unless you want anonymity)
3. Publish advisory

## Best Practices for Users

- Never commit `.env` - use `.env.example`
- Rotate ANTHROPIC_API_KEY if exposed
- Use `python -m pip` in venv, not global

Built with security first from Montevideo, UY.
